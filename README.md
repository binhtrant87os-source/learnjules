# LinkedIn Job Application Bot

This project is a Python-based application that automates the process of searching for and applying to jobs on LinkedIn. It uses web scraping to gather job listings and Selenium to automate the application process.

## Features

- **Job Scraping**: Searches for jobs on LinkedIn based on keywords and location, and extracts relevant information.
- **Automated Applications**: Automatically fills out and submits job applications using the user's profile information.
- **Application Tracking**: Keeps a record of all submitted applications and their status.

## Getting Started

### Prerequisites

- Python 3.6+
- Google Chrome

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/linkedin-job-bot.git
   ```
2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Set up your LinkedIn credentials in a `.env` file.

### Usage

Run the application from the command line:
```bash
python app.py
```
